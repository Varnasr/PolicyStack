# Roadmap

This document outlines the planned future development for PolicyStack.

## Phase 1: Foundation
- Define schema for scheme metadata (name, ministry, sector, beneficiaries, budget)
- Collect seed data for 10-20 flagship central schemes
- Document data collection methodology

## Phase 2: Budget Data
- Parse Union Budget PDF tables into structured CSV
- Track allocation vs. expenditure for key programs
- Build comparison views across fiscal years

## Phase 3: State-Level Expansion
- Add state budget data for 3-5 priority states
- Map schemes to development indicators
- Build scrapers for government data portals

---

*This roadmap evolves as the project grows.*
